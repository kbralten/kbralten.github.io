Hardware Projects
==================

Motor Drivers
-------------

-   [HO-Driver](https://github.com/kbralten/HO-Driver): A DC motor driver based on the A3959SB-T (PDIP version). It features a 555-based PWM generator for variable duty cycle control, a 7805-based voltage regulator for digital VDD, and strapping resistors to toggle between fast and slow decay modes.

Thermal Control
---------------

-   [lm317-fan-speed-controller](https://github.com/kbralten/lm317-fan-speed-controller): A robust, solid-state analog fan speed controller using an LM317 linear regulator and an MPSA27 Darlington transistor. It features a "soft start" ramp-up to protect the fan.
